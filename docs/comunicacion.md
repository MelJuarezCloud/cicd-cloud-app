# 3. Canal Oficial de Comunicación - Grupo 3

## 3.1 Evidencia del Grupo de Trabajo
- **Plataforma Seleccionada:** WhatsApp
- **Nombre del Grupo:** Grupo 3 - ESIT

## 3.2 Normas de Comunicación Asincrónica
1. **Etiquetado directo:** Usar @nombre cuando un asunto requiera la intervención o respuesta inmediata de un rol específico.
2. **Contexto completo:** Al notificar un fallo en el pipeline, incluir capturas del error en GitHub Actions y la rama afectada.
3. **Formalidad en Pull Requests:** Acompañar los PR de una breve descripción de lo implementado o probado.
4. **Centralización:** Todo acuerdo debe publicarse en el grupo oficial.

## 3.3 Horarios Acordados y Tiempos de Respuesta
- **Ventana de Disponibilidad:**
  - Lunes a Viernes: 8:00 AM – 9:30 PM
  - Sábados: 8:00 AM – 6:00 PM
- **Reunión Sincrónica Semanal:** Todos los Miércoles a las 6:30 PM (Duración: 30 a 45 minutos para revisión de avances).
- **Tiempos Máximos de Respuesta:**
  - Consultas de trabajo (en ventana disponible): Máximo 2 horas.
  - Aprobación o revisión de Pull Requests (PR): Máximo 24 horas.
